# プライバシーポリシー（ひな形）

**版:** 2026-08-16  
**サービス名（仮）:** sns-x（本番フォーク）

> 本ドキュメントは個人開発・小規模公開向けの**ひな形**です。個人情報保護法・電気通信事業法その他の要件に合わせ、専門家の確認を受けてから公開してください。法律助言ではありません。

## 1. 事業者

個人情報の取扱い責任者・連絡先は [お問い合わせ](/contact) に記載します。公開前に運営者名・連絡手段を必ず埋めてください。

## 2. 取得する情報

本サービスは、おおむね次の情報を取得します。

| 区分 | 例 |
|---|---|
| 登録情報 | メールアドレス、ハンドル、表示名、パスワード（ハッシュのみ保存） |
| プロフィール | 自己紹介、公開設定 |
| 利用データ | 投稿、いいね、フォロー、ブロック、ミュート、通報、閲覧に伴う技術ログ |
| 同意記録 | 利用規約・プライバシーポリシーへの同意日時および版 |
| 端末・通信 | IP アドレス、User-Agent、request_id（セキュリティ・監査用） |
| 任意の計測 | Sentry 等を有効にした場合のエラー情報（PII 送信は最小限に設定） |

DM 機能は提供しません。利用者間の私的メッセージは取り扱いません。

## 3. 利用目的

取得した情報は次の目的で利用します。

1. アカウント認証・セッション管理  
2. タイムライン・通知など本サービスの提供  
3. 不正利用防止、スパム・安全対策、モデレーション  
4. お問い合わせ対応、重要な規約変更の通知  
5. 障害対応・セキュリティ監査・サービス改善  

目的外利用は、法令に基づく場合または本人同意がある場合を除き行いません。

## 4. 第三者提供・委託

1. 法令に基づく場合を除き、本人同意なく第三者に個人データを提供しません。  
2. ホスティング・メール・監視（例: クラウド、Sentry）等に処理を委託することがあります。委託先には必要最小限のデータを渡し、適切な監督に努めます。  
3. 国外へのデータ移転がある場合は、移転先と保護措置を本ポリシーまたは別紙で明示します。

## 5. 保存期間

アカウント削除（消去）後は、法令・紛争対応・バックアップ保持に必要な期間を除き、合理的な期間内に削除または匿名化します。サーバログは運用上必要な期間保持したうえで削除します。

## 6. 安全管理

アクセス制御、通信の暗号化（本番では HTTPS）、権限分離、監査ログ等、取り扱うデータの内容に応じた安全管理措置を講じます。

## 7. 開示・訂正・削除等

本人から、保有個人データの開示・訂正・利用停止・消去等の請求があった場合、法令に従い合理的な範囲で対応します。手続きは [お問い合わせ](/contact) 経由で受け付けます。本人確認を求めることがあります。

## 8. Cookie・外部送信

本サービスの Web フロントは、認証トークンをブラウザのローカルストレージに保存する場合があります。広告目的のトラッキング Cookie は原則使いません。計測・エラー監視 SDK を導入する場合は、対象・送信先を本ポリシーまたは画面上で告知します（外部送信規律の対象となり得るため、公開前に確認してください）。

## 9. 未成年者

未成年者が利用する場合は、保護者の同意を得たうえでご利用ください。年齢確認機能は現状限定的です。

## 10. 改定

本ポリシーを改定する場合は、サービス上で告知します。登録時に同意した版はアカウントに記録されます。

## お問い合わせ

個人情報に関する問い合わせは [お問い合わせ](/contact) へ。
